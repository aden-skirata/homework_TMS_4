### 2. Побитовые операции. Для каждой пары: перевести числа в 2СС, выполнить побитовое И (AND), перевести результат обратно в 10СС. Пары: (45, 23), (78, 56), (123, 85), (156, 99), (255, 170) 

```
45 = 00101101
23 = 00010111 
and  00000101
1*2^0 + 1*2^2 = 1 + 4 = 5
```

```
78 = 01001110
56 = 00111000
and 00001000
1*2^3 = 8
```

```
123 = 01111011
85 = 01010101
and 01010001
1*2^0 + 1*2^4 + 1*2^6 = 1 + 16 + 64 = 81
```

```
156 = 10011100
99 = 01100011
and 00000000
0 = 0
```

```
255 = 11111111
170 = 10101010
and 10101010
1*2^1 + 1*2^3 + 1*2^5 + 1*2^7 = 2 + 8 + 32 + 128 = 170
```

### 3. IP-адресация  
#### Часть A — Полный разбор сети. Для каждого варианта найдите: адрес сети, broadcast, первый и последний хост, количество хостов.

```
IP: 192.168.10.77 Маска: 255.255.255.192 

255.255.255.192 = 1111111.11111111.11111111.11000000 = /26

77 = 01001101
192 = 11000000
and 01000000 = 64

network address = 192.168.10.64
broadcast = 192.168.10.127
first host = 192.168.10.65
last host = 192.168.10.126
hosts count = 62
``` 

```
IP: 10.10.10.200 Маска: 255.255.255.224

255.255.255.224 = 11111111.11111111.11111111.11100000 = /27

200 = 11001000
224 = 11100000
and 11000000 = 192

network address = 10.10.10.192
broadcast = 10.10.10.223
first host = 10.10.10.193
last host = 10.10.10.222
hosts count = 30
```
