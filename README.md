## Numbers and nets

### 1. Перевод чисел. Переведите числа из 10СС: в 2СС (с полным разбором через деление), затем результат представьте в 8СС и 16СС. Числа: 137, 245, 378, 512, 729, 845, 999, 1023, 2047, 4095. Требование: Для 2СС обязательно показать процесс деления на 2.

```
137/2 = 68 | 1
68/2 = 34 | 0
34/2 = 17 | 0
17/2 = 8 | 1
8/2 = 4 | 0
4/2 = 2 | 0
2/2 = 1 | 0
1/2 = 0 | 1

8CC 211
16CC 89
```
